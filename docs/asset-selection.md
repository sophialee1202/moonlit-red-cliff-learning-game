# MVP 素材與課文核對

## 素材決定

MVP 採用自製 SVG 水墨素材，避免把不相配的通用素材放進赤壁夜遊場景。場景底圖、可拖曳意象圖章和介面裝飾都存放在專案內，離線遊玩時不需要連到外部素材服務。

| 用途 | MVP 選擇 | 備註 |
| --- | --- | --- |
| 赤壁夜景 | 自製 SVG 山影、月色、江面、薄霧、小舟 | 以宣紙底色、墨灰與低彩度藍綠呈現。 |
| 意象組圖 | 自製月亮、清風、水波、白露、山影、小舟圖章 | 使用拖曳組圖，不評繪畫技巧。 |
| 介面與卡片 | Phaser Graphics 和本地字體 | 保持中文清晰，按鈕支援滑鼠與觸控。 |
| Kenney 素材 | 首版不採用 | 目前查到的 Kenney 候選以通用背景／介面或像素素材為主，未確認到適合此水墨赤壁場景的圖像。其他風格加入時再重新挑選。 |

Kenney 官方頁面列出的候選包含 [Background Elements](https://kenney.nl/assets/background-elements)、[UI Pack - Adventure](https://kenney.nl/assets/ui-pack-adventure) 和 [Pixel UI Pack](https://kenney.nl/assets/pixel-ui-pack)。前兩者的官方頁面標示為 CC0；Pixel UI Pack 也標示 CC0。這些素材不納入 MVP，故首版不需下載第三方圖像包。

## 《前赤壁賦》MVP 選句核對

下列首版片段依國語文學科中心「赤壁賦」原文逐句核對。主流程只顯示這些選句，完整篇文留作可展開的參考閱讀。該頁將〈赤壁賦〉列為課綱選文並標示作者蘇軾；正式教材中的字形、標點與注釋仍需依學校採用版本確認。

| 關卡 | 選句 | 遊戲用途 |
| --- | --- | --- |
| 月出東山 | 「清風徐來，水波不興。」「月出於東山之上，徘徊於斗牛之間。」「白露橫江，水光接天。」 | 點選景物線索，組合夜江意象，推想初遊時開闊、自在的感受。 |
| 洞簫聲起 | 「其聲嗚嗚然，如怨如慕，如泣如訴；餘音嫋嫋，不絕如縷。」 | 從聲音描寫找出由宴飲之樂轉向悲慨的線索。 |
| 客之悲 | 「哀吾生之須臾，羨長江之無窮。」 | 說明客人為何感到生命短暫、個體渺小。 |
| 水月之理 | 「逝者如斯，而未嘗往也；盈虛者如彼，而卒莫消長也。」 | 觀察蘇子如何以水月引出變與不變的觀點。 |
| 共享清風明月 | 「惟江上之清風，與山間之明月，耳得之而為聲，目遇之而成色；取之無禁，用之不竭。」 | 找出蘇子由思辨轉向共享自然之樂的文本證據。 |
| 結尾 | 「客喜而笑，洗盞更酌。」 | 觀察結尾如何呈現客的情緒變化。 |

來源：[國語文學科中心《赤壁賦》原文與語譯](https://cerclearning.tp.edu.tw/classical/datapage/153)。
